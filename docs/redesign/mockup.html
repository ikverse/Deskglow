Deskglow redesign mockup

One card per ticket in docs/redesign/TASKS.md, in the same order. Tick the ones you want done; the combined view applies every ticked [UI] task at once, and Copy selection gives you the line to paste back.

How the screens were drawn: layout, sizes, colours, radii, text and the default widget layout come from the code at 0.6.1 (Palette, Type, Components.kt, each screen file and DefaultLayout), at 1 px per dp. Material components use the Material 3 defaults of the app's Compose BOM (2026.02). The live readings are sample values (10:42, battery 76% charging, 31.4 °C, Cairo 27°), because the audit's phone captures are not in the repo. The drawn clock styles are built from plain boxes, so their letterforms are close to the app's but not identical.
